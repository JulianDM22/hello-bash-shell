1. Mostrar el directorio en el que estoy ahora: pwd
2. Cambiar a ldirectorio Documentos (o Documents) de tu sistema:
cd ~ (por si estoy en otra carpeta, ubicarme directamente en home)
ls -l (para saber exactamente como tengo nombrada esa carpeta)(aqui me doy cuenta que no la tengo)
3. Vuelve al mismo directorio (Documentos o Documents), pero esta vez usando una ruta absoluta completa:
Si tuviera la carpeta documentos, la ruta absoluta seria cd /home/user/Docs
4. Sube un nivel de jerarquia de directorios: cd ..
5. Lista el contenido del directorio actual en formato simple, luego largo y finalmente incluyendo archivos
ocultos: ls (simple)
ls -l (largo)
ls -a (oultos)
6. Consulta el manual de algun comando: man ls
7. Consulta la ayuda de algun comando: ls --help
8. Muestra tu nombre de usuario, la fecha y hora actuales y el calendario de este mes:
whoami (usuario)
date (fecha y hora)
cal (calendario de este mes)
9. Regresa al directorio donde comenzaste el primer ejercicio: cd -
10. Limpia pantalla: clear
